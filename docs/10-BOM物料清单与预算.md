## 3. 关键选型理由

| 项 | 理由 |
|---|---|
| 云 ECS ×3 全公网部署 | 免现场运维与搬运输；顾客可蜂窝直连（不依赖现场网络）；小程序合法域名天然合规 |
| CDN 分流 | 图片/静态 ≈90% 读流量在边缘命中：源站降压、现场出口仅承载 API（<5Mbps） |
| 云 2 台 ECS（聚合 16C32G + BE 2C4G） | 用户态合并论证通过（02 §5.1）：50 TPS / 200 QPS 远低于瓶颈；库存同进程直读零漂移；按月付费活动后释放 |
| Wi-Fi 6 AP ×3 | 5,000 人密集接入高并发终端能力；员工/顾客分 SSID |
| 双 CPE 异网（SIM 已办理） | 出口仅承载 API；断出口时顾客蜂窝兜底，成本极低买全天候安心 |
| 蓝牙 58mm 热敏 ×3 | 免驱动安卓 BLE 通吃；1 台热备应对最高频故障点 |
| 小型 UPS ×1（可选） | 仅保现场网络设备；服务器端由云电力冗余保障 |
| 对讲机 ×6 | 网络/蜂窝全拥塞时最后通信手段（RB-04 极端场景） |
