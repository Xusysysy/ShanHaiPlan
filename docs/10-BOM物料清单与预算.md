## 3. 关键选型理由

| 项 | 理由 |
|---|---|
| 迷你主机而非机架服务器 | 50 TPS / 500 QPS 负载远低于瓶颈；功耗 <15W×3 契合现场供电；静音 |
| Wi-Fi 6 AP ×3 而普通路由 ×3 | 5,000 人密集接入需要高并发终端能力（单 AP 建议 ≤80 终端）；员工/顾客分 SSID 隔离 |
| 双 CPE 异网 SIM | 出口仅为 NTP/管理，但断出口影响校时与远程支撑；成本 1k 内买全天候安心 |
| 蓝牙 58mm 热敏 ×3 | 单据轻量、免驱动、安卓 BLE 通吃；3 台含 1 台热备，打印机是现场最高频故障点 |
| UPS ×3 | SQLite 优雅停机保护 + 断电业务连续；500VA 撑 3 台迷你主机 30min+ 绰绰有余 |
| 对讲机 ×6 | 网络/小程序全挂时的最后通信手段（RB-04 场景） |
