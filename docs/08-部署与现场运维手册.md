# 08 · 部署与现场运维手册（Runbook）

> 文档版本 v1.0　|　目标：**活动日 2 小时内完成从开机到全绿**；现场任何故障 ≤5 分钟恢复业务

---

## 1. 软件交付物清单

| 交付物 | 形态 |
|---|---|
| `shs-trade` / `shs-catalog` / `shs-core` | 静态编译 Linux x86_64 二进制（rustls 内嵌，无动态依赖）+ `*.service` + `*.toml` |
| 小程序体验版二维码 | 彩排/正式双份 |
| 密钥包 `secrets-<活动代号>.zip` | K_CLI/K_ENT/JWT/内部令牌/激活码私钥（**离线保管，活动后销毁**） |
| 初始化脚本 `init_activity.sh` | 生成配置、证书、目录、库存导入 |
| 监控大屏页面 | 运维笔记本浏览器打开 |

## 2. 服务器初始化（活动前 1 天，可在机房/宿舍预做）

```bash
# 每台服务器（Debian 12 / Ubuntu 22.04，最小化安装 + ssh）
sudo useradd -r -s /usr/sbin/nologin shs
sudo install -m755 shs-core /usr/local/bin/   # 按机器替换
sudo mkdir -p /etc/shs /var/lib/shs /var/log/shs && sudo chown -R shs:shs /var/lib/shs
sudo cp shs-core.service /etc/systemd/system/
# 证书：现场自签 CA（init_activity.sh 一次性生成）
sudo systemctl enable --now shs-core && sudo systemctl status shs-core
# 时钟
sudo timedatectl set-ntp true && timedatectl | grep -E 'NTP|synchronized'
# 防火墙
sudo ufw default deny incoming
sudo ufw allow from 192.168.10.0/24 to any port 443 proto tcp
sudo ufw allow from 192.168.10.30 to any port 22 proto tcp   # 仅运维机 SSH
sudo ufw enable
```

**配置要点（TOML 节选，F1 示例）**：

```toml
[server]
listen = "0.0.0.0:443"
tls_cert = "/etc/shs/f1.crt"
tls_key  = "/etc/shs/f1.key"

[activity]
code = "SH2026"
center = { lat = 30.000000, lng = 120.000000 }   # 现场实测后回填
radius_m = 800
k_cli = "<从密钥包注入>"
k_ent = "<从密钥包注入>"

[peer]
be_url = "https://192.168.10.23"
internal_token = "<注入>"
f2_feed = "wss://192.168.10.22/ws/inventory-feed"

[trade]
batch_max_orders = 50
batch_interval_ms = 1000
retry_backoff = [1, 2, 4, 5, 5]
```

## 3. 现场组网 SOP（活动日 T-2h 起，预计 60min）

| 步骤 | 动作 | 验证 | 时长 |
|---|---|---|---|
| N1 | 布线：CPE→路由→SW1（服务器）/SW2（PoE AP） | 链路灯全亮 | 15min |
| N2 | CPE 上电激活，确认蜂窝信号 ≥ -100dBm 位置（天线靠窗/高位） | CPE 管理页在线 | 5min |
| N3 | 三服务器上电接入 SW1，静态 IP 10.21/22/23 | ping 通网关 | 5min |
| N4 | AP ×3 上电，SSID：`SH-Staff`（隐藏，员工）/`SH-Guest`（开放，顾客浏览） | 真机连 SSID | 10min |
| N5 | 现场实测打点：会场中心坐标回填 F1 配置并重启 | 真机围栏通过 | 10min |
| N6 | 走点测覆盖（入口/队伍/提货/纪念品/出口）| 全点位 RSSI ≥ -70dBm | 15min |
| N7 | 真机全链路冒烟（见 §5 冒烟清单） | 全绿 | 10min |

> 双 CPE 策略：主 CPE 正常承载；备用 CPE 保持关机冷备（换插即用，切换 ≤5min）。

## 6. 故障 Runbook（按现象索引）

### RB-01 员工端收不到订单（小票停打）

```
1 BE 大屏 staff 列表 → 该工位在线?
2 离线 → 员工端杀掉小程序重开（重连自动补拉 last_seq）
3 仍离线 → 看该终端 Wi-Fi（SH-Staff 信号）；换热点/挪位置
4 BE 进程异常 → systemctl restart shs-core（≤30s；订单不丢）
5 全线停打 → 启用手写模式：ADMIN 大屏导出待打清单，手写单号+品名，事后补录
```

### RB-02 顾客扫码报「2FA 已过期」

```
1 让顾客进 我的2FA码 → 检查校时状态（红/黄）→ 点「重新校时」→ 重出码
2 仍失败 → 员工端手输小票号/订单号反查（PICKUP/ADMIN 权限）
3 无小票 → ADMIN 按 wxid 查订单 + 身份确认（学生证/工牌）→ 放行留痕
```

### RB-03 库存对不上（疑似超卖/少卖）

```
1 冻结该 SKU：ADMIN adjust 停售（state SOLD_OUT）
2 F1 metrics 导出该 SKU sold；BE 导出订单明细合计
3 以 BE 账本为准纠偏；缺口按先到先得保留，无法履约的订单现场沟通换品/退款
4 处理全程 audit_log 留痕
```

### RB-04 出口 Wi-Fi 全断

```
1 入场/核验走客户端离线校验 + 员工端半离线（入口本来即半离线设计）
2 提货/纪念品：启动「登记本模式」——手记 wxid 后 4 位+指纹尾+发放项，恢复后补录
3 指挥台同步启动对讲机沟通，恢复正常后 10min 内补录完成
```

### RB-05 CPE 出口断

```
1 核心交易不受影响（全内网）；仅 NTP/校时降级
2 2FA 依赖已校钟，1~2h 内漂移可容忍；>2h 且未恢复 → 切备用 CPE（≤5min）
3 切换后抽查 1 台真机校时状态
```

### RB-06 打印机队列堵/卡纸

```
1 员工端「手动补打」；连续卡纸换备用机（提货区备机顶上）
2 纸卷换装 SOP（打印侧盖打开、热敏面朝出纸口、留 5cm）
```

### RB-07 恶意刷单/异常账号

```
1 F1 metrics 指纹告警列表 → 大屏
2 ADMIN 对嫌疑 wxid：pause 单人下单（adjust freeze）
3 现场安保沟通；不现场撕破脸，履约环节人工把关
```

## 7. 活动结束收尾（30min）

```
□ 下单入口关闭（panic pause）；广播/海报提示
□ 数据三备份：BE VACUUM INTO U盘×2 + 运维笔记本（F1 WAL、F2 目录一并打包）
□ 纪念品台账 vs 剩余实物盘点（RB 反向对账）
□ 员工端全员退出登录；密钥包当场销毁登记
□ 设备回收清点（对照 BOM 表逐项打勾）；租借设备当日归还
□ 感谢信/复盘会时间通告
```
