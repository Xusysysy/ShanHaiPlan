# 08 · 部署与现场运维手册（Runbook）

> 文档版本 v1.1　|　v1.1：三服务迁移公有云（公网部署）、CDN 分流、SIM 已办理
> 目标：**活动日 1 小时内完成现场接入搭建到全绿**（服务器已在云端就绪）；任何故障 ≤5 分钟恢复业务

## 1. 云端部署（活动前完成，非现场工作）

### 1.1 云资源清单

| 资源 | 规格 | 说明 |
|---|---|---|
| ECS edge（前端聚合） | **16C32G**，盘 500G，EIP 带宽峰值 500M（按流量计费） | Nginx/Caddy 网关（SNI 分流 api/static）+ `shs-catalog` + `shs-trade` 双进程 |
| ECS be | 2C4G，系统盘 40G + 数据盘 40G | `shs-core`；公网 IP |
| CDN | 域名 `static.<备案域名>`，CNAME → CDN；回源 `edge.<域名>` | 缓存图片/静态；**API 路径不配置缓存** |
| DNS | `edge / be / static.<域名>` A/CNAME 记录（可保留 f1/f2 别名） | 备案域名（W1 核对，周期 1–3 周） |
| 证书 | 云免费证书 ×3（edge/be/static），自动续期 | TLS1.3 |
| 安全组 | 两台 ECS 入方向仅 443/TCP；SSH 22 仅限运维出口 IP + 密钥 | 聚合→BE 走公网域名 + 内部令牌（同 VPC 可选内网优化） |

### 1.2 服务器初始化（活动前 1 天）

```bash
# 每台 ECS（Debian 12 / Ubuntu 22.04）
sudo useradd -r -s /usr/sbin/nologin shs
sudo install -m755 shs-catalog /usr/local/bin/         # edge 机：catalog+trade+网关；be 机：core（按节点替换）
sudo mkdir -p /etc/shs /var/lib/shs /var/log/shs && sudo chown -R shs:shs /var/lib/shs
sudo cp shs-catalog.service shs-trade.service /etc/systemd/system/
sudo systemctl enable --now shs-catalog shs-trade && sudo systemctl status shs-catalog
# 网关（edge 机）：Caddy/Nginx 按 SNI 分流 api/static → 127.0.0.1:8443/8444
# 时钟：云镜像默认 chrony 对云 NTP——验证
chronyc tracking | grep -E 'Stratum|Last offset'
# 防火墙（叠加云安全组）
sudo ufw default deny incoming
sudo ufw allow 443/tcp
sudo ufw allow from <运维出口IP> to any port 22 proto tcp
sudo ufw enable
```

**配置要点（TOML 节选，聚合机 trade 进程示例）**：

```toml
[server]
listen = "127.0.0.1:8444"              # 网关回源；证书由网关终结
tls_cert = "/etc/shs/edge.crt"         # 云证书下发或 certbot 续期
tls_key  = "/etc/shs/edge.key"

[activity]
code = "SH2026"
center = { lat = 30.000000, lng = 120.000000 }   # 彩排实测后回填
radius_m = 800
k_cli = "<从密钥包注入>"
k_ent = "<从密钥包注入>"

[peer]
be_url = "https://be.<域名>"           # 公网域名互调 + 内部令牌
internal_token = "<注入>"
f2_feed = "wss://f2.<域名>/ws/inventory-feed"

[trade]
batch_max_orders = 50
batch_interval_ms = 1000
retry_backoff = [1, 2, 4, 5, 5]
```

## 3. 现场接入 SOP（活动日 T-1h 起，预计 40min）

| 步骤 | 动作 | 验证 | 时长 |
|---|---|---|---|
| N1 | 布线：CPE → 核心路由 → PoE 交换机（AP）/ 千兆交换机（运维本/大屏/打印机供电位） | 链路灯全亮 | 10min |
| N2 | CPE 上电，天线高位靠窗；确认蜂窝信号 ≥ -100dBm（SIM 已办理，开机即用） | CPE 管理页在线；经 CPE 打开 `f1.<域名>/healthz` ✓ | 5min |
| N3 | AP ×3 上电（PoE），SSID：`SH-Staff`（隐藏）/`SH-Guest`（开放） | 真机连 SSID 出网 | 5min |
| N4 | 现场实测打点：会场中心坐标回填 F1 配置（管理台远程或 SSH） | 真机围栏通过 | 5min |
| N5 | 走点测覆盖（入口/队伍/提货/纪念品/出口）；同步记录「蜂窝直连可用性」抽查（关 Wi-Fi 用 4G/5G 打开小程序） | 全点位 RSSI ≥ -70dBm；蜂窝全通 | 10min |
| N6 | 真机全链路冒烟（见 §5） | 全绿 | 5min |

> 双 CPE 策略：主 CPE 承载；备用 CPE 冷备换插即用 ≤5min。**顾客侧关键降级路径：断 Wi-Fi 用自身蜂窝直连云端**——抽查至少 3 家不同运营商。

## 6. 故障 Runbook（按现象索引）

### RB-01 员工端收不到订单（小票停打）

```
1 BE 大屏 staff 列表 → 该工位在线?
2 离线 → 员工端杀掉小程序重开（重连自动补拉 last_seq）；仍离线 → 该终端切蜂窝重连
3 BE 进程异常 → 云控制台/systemctl restart shs-core（≤30s；订单不丢）
4 全线停打 → 手写模式：ADMIN 大屏导出待打清单，手写单号+品名，事后补录
```

### RB-02 顾客扫码报「2FA 已过期」

```
1 我的2FA码 → 检查校时状态（红/黄）→ 点「重新校时」（公网可达）→ 重出码
2 仍失败 → 员工端手输小票号/订单号反查（PICKUP/ADMIN 权限）
3 无小票 → ADMIN 按 wxid 查订单 + 身份确认（学生证/工牌）→ 放行留痕
```

### RB-03 库存对不上（疑似超卖/少卖）

```
1 冻结该 SKU：ADMIN adjust 停售（SOLD_OUT）
2 F1 metrics 导出 sold；BE 导出订单明细合计
3 以 BE 账本为准纠偏；缺口按先到先得保留，无法履约现场沟通换品/退款
4 全程 audit_log 留痕
```

### RB-04 现场 Wi-Fi 全断

```
1 顾客：自动/引导切自身蜂窝直连云端（核心路径，冒烟已验证三家运营商）
2 员工：终端切蜂窝；入口区本就半离线设计（客户端离线验签 + 异常登记本）
3 极端（蜂窝也拥塞）：登记本模式手记，恢复后 10min 内补录
```

### RB-05 CPE 出口断/拥塞

```
1 顾客切蜂窝直连（同 RB-04）——交易链路不经 CPE 亦可闭环
2 切备用 CPE（≤5min）；恢复后抽查 1 台真机校时状态
```

### RB-06 打印机队列堵/卡纸

```
1 员工端「手动补打」；连续卡纸换备用机
2 换纸 SOP 贴工位（热敏面朝出纸口、留 5cm）
```

### RB-07 恶意刷单/异常账号

```
1 F1 metrics 指纹告警列表 → 大屏
2 ADMIN 对嫌疑 wxid 冻结下单；现场安保沟通
3 公网暴露面大：确认限流生效（429 指标）；必要时云控制台开 WAF/CC 防护
```

### RB-08 CDN 缓存未刷新（改图/改价不生效）

```
1 图片 URL 已版本化（?v=hash）→ 正常更新天然刷新
2 未版本化资源 → 云控制台「URL 刷新/目录刷新」（≤5min 生效）
3 API 不允许配置 CDN 缓存——核对缓存规则是否误加 /api/*
```

## 7. 活动结束收尾（30min）

```
□ 下单入口关闭（panic pause）；广播/海报提示
□ 数据三备份：BE VACUUM INTO → 云对象存储 1 份 + 运维笔记本 1 份 + U 盘 1 份（F1 WAL、F2 目录一并打包）
□ 纪念品台账 vs 剩余实物盘点（反向对账）
□ 员工端全员退出登录；密钥包当场销毁登记
□ 云资源处置：ECS 制作最终快照后**释放/降配**（控制成本）；CDN 停用或保留只读
□ 设备回收清点（对照 BOM 逐项打勾）；租借设备当日归还
```
