# 03 · 接口与通信协议设计

> 文档版本 v1.0　|　所有接口除非注明均为 HTTPS/WSS（TLS1.3），JSON UTF-8
> 服务地址（现场内网）：F1 `https://f1.shanhai.local`　F2 `https://f2.shanhai.local`　BE `https://be.shanhai.local`

---

## 1. 通用约定

### 1.1 认证方式

| 调用方 | 凭证 | 携带方式 |
|---|---|---|
| 顾客（匿名浏览 F2） | 无 | —（限流按 IP + 指纹） |
| 顾客（交易 F1） | `X-WX-Id`（openid）+ `X-Device-Fp` | 请求头 |
| 员工 | JWT（BE 签发） | `Authorization: Bearer <jwt>` |
| 服务间（F1→BE、BE→F1） | 静态服务令牌 | `X-Internal-Token`（TOML 配置，每场轮换） |

### 1.2 员工 JWT 载荷

```json
{
  "sid": "STF0007",              // 员工ID
  "role": "PICKUP",              // ENTRY | QUEUE | PICKUP | SOUVENIR | FLOAT | ADMIN
  "name": "张三",
  "act": "SH2026",               // 活动代号
  "iat": 1788000000,
  "exp": 1788007200              // 2h，员工端自动静默续签
}
```

### 1.3 统一响应包

```json
// 成功
{ "ok": true, "data": { ... }, "ts": 1788000000123 }
// 失败
{ "ok": false, "err": { "code": "STOCK_INSUFFICIENT", "msg": "库存不足", "detail": { "sku": "SKU008" } }, "ts": 1788000000123 }
```

### 1.4 全局错误码表

| code | HTTP | 含义 | 客户端处置 |
|---|---|---|---|
| `AUTH_REQUIRED` | 401 | 未携带/无效凭证 | 引导重新登录/激活 |
| `FORBIDDEN_ROLE` | 403 | 角色无权限 | 提示找管理员 |
| `GEOFENCE_FAIL` | 403 | 不在会场围栏内 | 引导开启定位/到场 |
| `ENTRY_NOT_VERIFIED` | 403 | 未完成入场核验 | 引导走入场流程 |
| `ENTRY_CODE_INVALID` | 400 | 入场动态码校验失败 | 重新扫码 |
| `STOCK_INSUFFICIENT` | 409 | 库存不足 | 刷新库存重选 |
| `LIMIT_EXCEEDED` | 409 | 超出限购 | 提示限购数量 |
| `DUPLICATE_ORDER` | 409 | 已存在未完成订单 | 引导查看已有订单 |
| `ORDER_NOT_FOUND` | 404 | 订单不存在 | 联系员工 |
| `ALREADY_FULFILLED` | 409 | 订单已核销 | — |
| `ALREADY_CLAIMED` | 409 | 纪念品已领取 | 拦截发放 |
| `CODE_EXPIRED` | 400 | 2FA 码时间窗外 | 让顾客刷新出示 |
| `CODE_BAD_SIG` | 400 | 2FA/入场码签名错误 | 换码重试/防伪 |
| `RATE_LIMITED` | 429 | 限流 | 退避重试 |
| `INTERNAL` | 500 | 服务内部错误 | 重试 + 上报 |

### 1.5 通用字段

- 时间：Unix 毫秒（`ts`）；2FA 窗口用 Unix 秒；
- ID：订单 `ULID`（26 位），SKU `SKU+\d{3}`，员工 `STF+\d{4}`，入口 `EN+\d`；
- 分页：`?page=1&page_size=20`，响应 `data.total / data.items`。

## 2. F1 接口（front-trade）

### 2.1 时间服务

**GET** `/api/v1/time` → 用于客户端/员工端校钟

```json
{ "ok": true, "data": { "server_ts": 1788000000123 } }
```

> 客户端校时算法：取样 5 次，取单次往返 RTT 最小者的 `server_ts + rtt/2`，`offset = server_ts - local_ts` 缓存；之后每 10min 重校一次。

### 2.2 入场登记

**POST** `/api/v1/session/entry`

```json
// 请求
{
  "wxid": "oX1ab...",              // openid
  "device_fp": "fp:9f2c...",       // 设备指纹（见05）
  "entry_check": {                  // 入场动态码校验材料
    "entrance_id": "EN1",
    "window": 894000000,            // 扫码时刻所属 2s 窗
    "sig": "a1b2c3d4e5f6",          // 客户端回传的原始 sig 供服务端二次复核
    "client_ts": 1788000000000,     // 扫描瞬间客户端时间戳
    "verified_local": true          // 客户端本地校验结果
  }
}
// 响应
{ "ok": true, "data": { "registered": true, "first_time": true, "server_ts": 1788000000123 } }
```

- 服务端二次复核 HMAC 与时间窗（双保险，防客户端伪造 verified_local）；
- 重复 wxid：返回成功，`first_time=false`；
- 指纹风控：同一指纹对应 ≥3 个 wxid → 记录告警（不阻断，交现场处置）。

### 2.3 下单

**POST** `/api/v1/orders`

```json
// 请求
{
  "wxid": "oX1ab...",
  "device_fp": "fp:9f2c...",
  "items": [ { "sku": "SKU008", "qty": 2 } ],
  "client_window": 894000000,
  "nonce": "b3a9..."                // 防重放
}
// 响应 201
{
  "ok": true,
  "data": {
    "order_id": "01J9ZK3W8XG0M2N4P5Q6R7S8T9",
    "items": [ { "sku": "SKU008", "name": "山海徽章", "qty": 2, "price": 1500 } ],
    "total": 3000,
    "state": "BUFFERED"
  }
}
```

- 金额单位：**分**（整数），避免浮点；
- 幂等：同 `wxid + nonce`（5s 窗内）重复提交返回同一订单；
- 校验顺序：登记 → 限购（`Σ历史+本次 ≤ limit`）→ 库存 → 原子扣减 → WAL。

### 2.4 员工查下单状态（队列中途校验）

**GET** `/api/v1/staff/order-status?wxid={openid}`　🔐 员工 JWT（QUEUE/PICKUP/FLOAT/ADMIN）

```json
{ "ok": true, "data": {
    "registered": true,
    "ordered": true,
    "order_id": "01J9ZK3W8X...",
    "ordered_at": 1788001234567,
    "fulfilled": false,
    "scan_alert": false          // 该指纹扫码频率异常时 true
} }
```

### 2.5 管理接口（F1）　🔐 ADMIN JWT

| 方法/路径 | 说明 |
|---|---|
| `POST /api/v1/admin/inventory/init` | 起始库存初始化 `{"items":[{"sku":"SKU008","stock":120,"limit":2}]}`（活动前） |
| `POST /api/v1/admin/inventory/adjust` | 应急调库存 `{"sku":"SKU008","delta":-5,"reason":"破损"}`（留痕） |
| `POST /api/v1/admin/panic` | 应急开关 `{"pause_orders":true}`（暂停/恢复全场下单） |
| `GET /api/v1/admin/metrics` | 库存/登记/投递积压指标（大屏轮询） |

### 2.6 内部接口（F1 ↔ BE）　🔐 `X-Internal-Token`

| 方法/路径 | 方向 | 说明 |
|---|---|---|
| `POST /api/v1/internal/orders/release` | BE→F1 | 提货核销后释放缓存 `{"order_ids":["01J..."]}` → F1 将 wxid「已下单」态转「已完成」，清理 Outbox 资源 |
| `GET /healthz` | 全部 | `{"ok":true,"uptime":..., "outbox_backlog": 12}` |

## 3. F2 接口（front-catalog）

### 3.1 匿名商品查询

**GET** `/api/v1/products?page=1&page_size=20&keyword=徽章`

```json
{ "ok": true, "data": { "total": 87, "items": [ {
    "sku": "SKU008",
    "name": "山海徽章",
    "desc": "限量珐琅徽章",
    "price": 1500,
    "image": "/static/products/sku008.webp",
    "stock": 118,             // F1 副本，可能≤3s延迟
    "limit": 2,
    "state": "ON_SALE"        // ON_SALE | SOLD_OUT | HIDDEN
} ] } }
```

**GET** `/api/v1/products/{sku}` → 单品详情（同上结构）
**GET** `/static/products/{file}` → 图片/静态资源（`Cache-Control: max-age=86400`，ETag）

### 3.2 员工库存订阅（WS）

**GET（升级）** `wss://f2.shanhai.local/ws/inventory`　🔐 员工 JWT（任意角色）

```json
// 连接建立后服务端先推全量，随后增量（≤1s）
{ "type": "inventory.snapshot", "ts": ..., "data": { "SKU008": 118, "SKU009": 0 } }
{ "type": "inventory.delta",    "ts": ..., "data": { "SKU009": 3 } }
// 心跳：server ping → client pong（15s 周期）
```

### 3.3 管理接口（F2）　🔐 ADMIN JWT

| 方法/路径 | 说明 |
|---|---|
| `POST /api/v1/admin/products` | 新建/更新商品（multipart 或 JSON+图片 URL） |
| `POST /api/v1/admin/products/import` | CSV 批量导入 |
| `POST /api/v1/admin/products/{sku}/image` | 上传图片（webp/png ≤2MB，服务端压缩转 webp） |

## 4. BE 接口（backend-core）

### 4.1 员工激活与登录

**POST** `/api/v1/staff/activate`　（一次性激活码换 JWT）

```json
// 请求（扫码得到）
{ "activate_token": "ACT_9f8e...", "profile": { "name": "张三", "dept": "义卖一组", "phone_tail": "1234" } }
// 响应
{ "ok": true, "data": { "jwt": "eyJhbGciOi...", "staff": { "sid": "STF0007", "role": "PICKUP" } } }
```

- 激活 token：一次性（用后即焚）+ 5 分钟过期 + Ed25519 签名（离线可验）；
- 实名绑定：`profile` 写入员工表，满足「组织根据员工 ID 实名绑定」。

**POST** `/api/v1/staff/refresh`　→ JWT 续签（旧 token 未过期方可）

### 4.2 员工 WS 长连接

**GET（升级）** `wss://be.shanhai.local/ws/staff`　🔐 员工 JWT（首包携带）

```json
// 通用信封
{ "v": 1, "type": "...", "seq": 1042, "ts": 1788000000123, "payload": { ... } }

// BE → 员工：新订单（配货打印）
{ "type": "order.new", "payload": {
    "order_id": "01J9ZK3W8X...",
    "items": [ { "sku": "SKU008", "name": "山海徽章", "qty": 2 } ],
    "zone": "PICKUP", "created_at": 1788000000000 } }

// 员工 → BE：打印回执
{ "type": "order.printed", "payload": { "order_id": "01J9ZK...", "staff_id": "STF0007" } }

// BE → 员工：任务分发（如补货、支援）
{ "type": "task.new", "payload": { "task_id": "TSK0031", "zone": "QUEUE", "text": "SKU009 补货 20 件" } }

// 心跳：ping/pong 15s；45s 无心跳判离线，订单改派在线同区员工
```

> 投递可靠性：`order.new` 带 `seq`，员工端 ACK（`order.printed` 或 `ack`）；断线重连后 BE 按员工角色补发未 ACK 订单（幂等打印由员工端按 order_id 去重）。

### 4.3 提货核销

**POST** `/api/v1/staff/orders/{order_id}/pickup`　🔐 PICKUP/FLOAT/ADMIN

```json
// 请求
{ "code_payload": "SHC1.oX1ab....894000000.a1b2c3d4" }   // 顾客2FA码原文
// 响应（成功）
{ "ok": true, "data": { "order_id": "01J9ZK...", "state": "FULFILLED", "fulfilled_at": ... } }
// 已核销 → 409 ALREADY_FULFILLED
```

- BE 本地验签 2FA 码并确认 `code_payload` 解出的 wxid 与订单 wxid 一致；
- 成功后异步回调 F1 `orders/release`，并推送原打印工位 `order.done` 提示。

### 4.4 纪念品

**GET** `/api/v1/staff/souvenir/check?code_payload={...}`　🔐 SOUVENIR/FLOAT/ADMIN

```json
{ "ok": true, "data": { "claimed": false, "wxid_masked": "oX1***ab" } }
```

**POST** `/api/v1/staff/souvenir/claim`

```json
// 请求
{ "code_payload": "SHC1.oX1ab...", "sku": "MEMO-A" }
// 响应
{ "ok": true, "data": { "claim_id": 412, "claimed_at": ... } }
// 重复 → 409 ALREADY_CLAIMED（台账 wxid+指纹 唯一约束兜底）
```

### 4.5 管理接口（BE）　🔐 ADMIN

| 方法/路径 | 说明 |
|---|---|
| `POST /api/v1/admin/staff/activate-codes` | 批量生成员工激活二维码材料 `[{"sid":"STF0007","role":"PICKUP"}]` → 返回带签名的 activate_token 列表 |
| `GET /api/v1/admin/staff` | 员工在线状态/实名列表 |
| `POST /api/v1/admin/tasks` | 下发任务 `{"zone":"QUEUE","text":"..."}` |
| `GET /api/v1/admin/dashboard` | 大屏聚合：入场数/订单数/各SKU售出/积压/员工在线 |
| `GET /api/v1/admin/export?type=orders|souvenir|registry` | CSV 导出（可选 wxid 脱敏 `?mask=1`） |

### 4.6 内部接口（F1→BE）　🔐 `X-Internal-Token`

**POST** `/api/v1/internal/orders/batch`

```json
// 请求
{ "batch_id": "01J9ZL...", "orders": [ {
    "order_id": "01J9ZK3W8X...", "wxid": "oX1ab...", "device_fp": "fp:9f2c...",
    "items": [ { "sku": "SKU008", "qty": 2, "price": 1500 } ],
    "total": 3000, "created_at": 1788000000000, "seq": 1042 } ] }
// 响应（全部幂等：已存在者返回 existed=true）
{ "ok": true, "data": { "acked": [ { "order_id": "01J9ZK...", "existed": false } ] } }
```

- F1 以 `batch_id` 追踪；**in-flight=1 保证批间保序**；批内按 `seq` 排序落库；
- BE 落库后立即按 `zone` 推送员工端。

## 5. WS 通道总表

| 通道 | 方向 | 用途 | 心跳 | 断线策略 |
|---|---|---|---|---|
| `F1 → F2 /ws/inventory-feed`（服务间） | F1→F2 | 库存快照+增量 | 15s | F2 断线重连即拉全量快照 |
| `F2 → 员工 /ws/inventory` | F2→员工 | 库存推送 | 15s | 自动重连，退避 1s→5s |
| `BE → 员工 /ws/staff` | BE↔员工 | 订单/任务/回执 | 15s | 重连后补发未 ACK；重连请求带 `last_seq` |
| 客户端 | — | **无 WS**，HTTPS 轮询 F2（30s，页面活跃时）+ 下单时 F1 权威校验 | — | — |

## 6. 2FA 码与二维码载荷规范（跨端契约）

### 6.1 窗口与容差（核心参数，双端实现必须一致）

```
WINDOW_SEC = 2                       // 每 2s 一个窗口
window(t)  = floor(unix_seconds(t) / 2)
校验通过条件：存在 w ∈ {window(now)-2 .. window(now)+2} 使签名匹配
       等价于时间戳偏移 |Δt| ≤ 5s（覆盖 ±4s 至 ±5s 边界带）
```

### 6.2 客户 2FA 码（SHC1）

```
payload = "SHC1." + b32(openid) + "." + window + "." + sig
sig     = hex( HMAC-SHA256( K_CLI, openid || "|" || window ) )[0..12]   // 12 hex
```

- `K_CLI`：活动级密钥，客户端与员工端共享（随活动配置分发 + 混淆存储）；
- 展示形态：小程序 Canvas 二维码 + 底部 2s 倒计时进度条；**每 2s 重绘**；
- 员工端扫码 → 验 sig 与窗口 → 解出 openid。

### 6.3 入场动态码（SHE1）

```
payload = "SHE1." + entrance_id + "." + window + "." + sig
sig     = hex( HMAC-SHA256( K_ENT, entrance_id || "|" || window ) )[0..12]
```

- 大屏每 2s 重绘；客户端 `wx.scanCode` 后**离线校验**（小程序内置 `K_ENT` + 本地时间窗）；
- 校验失败处理：`CODE_EXPIRED` → 重扫；`CODE_BAD_SIG` → 人工通道。

### 6.4 员工激活码（ACT1）

```
payload = "ACT1." + sid + "." + role + "." + expiry_unix + "." + sig
sig     = base64url( Ed25519_sign( K_STAFF_ADMIN, sid|role|expiry ) )   // 一次性 token 另行 BE 存库校验
```

## 7. 限流与防刷策略

| 端点 | 规则 | 动作 |
|---|---|---|
| F2 匿名商品 | 30 req/min/IP+fp | 429 |
| F2 图片 | 60 req/min/IP+fp | 429 |
| F1 entry | 5 req/min/wxid | 429 |
| F1 orders | 10 req/min/wxid；同 nonce 5s 去重 | 429/幂等返回 |
| 员工核销/领取 | 30 req/min/staff | 429 |
| 全局 | 单 IP 300 req/min | 429 + 告警 |

## 8. 协议版本与兼容

- REST 路径带 `/v1`；WS 信封带 `"v":1`；不兼容变更升版本号；
- 小程序与服务端同场发布，活动冻结后**禁止接口漂移**（变更走联调回归）。
