# 06 · 小程序端设计（客户端 + 员工端）

> 文档版本 v1.0　|　技术：微信原生小程序（WXML/WXSS/TypeScript）。需求所述「H5」指页面渲染形态；因扫码/定位/蓝牙打印能力要求，**不采用 web-view 内嵌 H5**（决策记录见 02 §6.2）
> 一个小程序、两套身份：顾客 = 默认；员工 = 激活码解锁（角色决定可见页面）

## 3. 关键实现要点

### 3.1 2FA 码组件（性能敏感）

```typescript
// features/twofa/index.ts（节选）
// 每 2s 重绘 Canvas 二维码；页面 onHide 停止定时器（省电）
const REDRAW_MS = 2000;
export function startCodeLoop(canvas, openid, kCli, getOffset) {
  let timer = 0;
  const draw = () => {
    const code = customerCode(openid, kCli, getOffset());   // 05 §1.1 契约
    drawQr(canvas, code); drawProgress(canvas, phaseOfNow()); // 2s 进度条
  };
  draw();
  timer = setInterval(draw, REDRAW_MS);
  return () => clearInterval(timer);
}
```

- 二维码渲染用 Canvas 2D（`wx.createSelectorQuery`），避免每 2s 重建节点；
- 前台校时状态展示：`绿=offset≤1s / 黄=1~4s / 红=≥4s 提示重校`。

### 3.2 设备指纹（shared/crypto/fingerprint.ts）

```typescript
export async function deviceFingerprint(): Promise<string> {
  const d = wx.getDeviceInfo(), s = wx.getAppBaseInfo(), w = wx.getWindowInfo();
  const raw = [d.model, d.system, d.platform, d.benchmarkLevel, s.SDKVersion, s.version,
    `${w.screenWidth}x${w.screenHeight}@${w.pixelRatio}`, s.language,
    new Date().getTimezoneOffset()].join(";");
  return "fp:" + sha256hex(raw).slice(0, 32);   // 05 §2.1 契约
}
```

- 结果缓存于 storage（同设备稳定）；`benchmarkLevel` 缺失字段用 `""` 占位。

### 3.3 入场扫码（features/gate）

```
流程：wx.scanCode → payload=SHE1.* → 本地验签(±2窗) → 失败分支：
  CODE_EXPIRED → toast「二维码已过期，请重扫」→ 自动重扫
  CODE_BAD_SIG → toast「无效二维码」→ 记录 + 人工通道提示
通过 → 记录 client_ts → POST F1 /session/entry → 成功后预取商品列表缓存
```

- 半离线兼容：F1 不可达时本地记 `pending_entry` 队列，恢复后重放（入口区 Wi-Fi 弱覆盖场景）。

### 3.4 WS 客户端（shared/ws）

```typescript
// 统一能力：心跳 15s / 断线重连退避 1s→2s→4s→5s 封顶 / last_seq 补拉 / 按 type 分发
class WsClient {
  connect(url, token, lastSeq) { ... }      // BE /ws/staff 或 F2 /ws/inventory
  on(type, handler) { ... }                 // order.new / inventory.delta / task.new
  ack(seq) { ... }                          // printed / done
}
```

- 员工端从后台回前台时强制 `lastSeq` 补拉（`order.replay`）；
- 打印去重：本地 `printed_order_ids` LRU（容量 200）。

### 3.5 蓝牙热敏打印（shared/printer，ESC/POS）

```
初始化：wx.openBluetoothAdapter → 过滤打印机 MAC（配置下发）→ 配对缓存
打印：小票模板(58mm, 32字符/行) → ESC/POS 字节流 → wx.writeBLECharacteristicValue 分包(≤20B)
模板：
  ===== 山海企划 · 义卖 =====
  单号: 01J9ZK3W8X...
  时间: 2026-09-12 14:03:22
  --------------------------
  山海徽章 x2        ¥30.00
  --------------------------
  合计:              ¥30.00
  凭此小票至【提货区】提货
  出口凭 2FA 码领纪念品
回执：打印成功 → order.printed {order_id}
```

- 失败重试 2 次后人工兜底（页面上「手动补打」按钮常驻）；
- 兼容主流程机型：佳博/芯烨 58mm 蓝牙款（BOM）。

### 3.6 弱网策略

- 商品列表/详情带本地缓存（storage + 时间戳 5min），弱网读缓存；
- 下单请求超时 8s、自动重试 1 次（幂等 nonce 保证不重复下单）；
- 全局网络状态监听，顶部横幅提示「网络不佳，库存可能延迟」。

## 4. 体验与视觉基线

- 主题：山海企划 VI（主色、活动 Logo、义卖声明横幅「公益义卖 · 收入全部捐出」占位）；
- 无障碍：字号 16rpx 基准、大按钮（老人机可点）、核心操作双击防误触；
- 性能预算：首屏可交互 ≤2s（缓存命中 ≤0.5s）；2FA 页面常驻内存占用 ≤120MB；
- 埋点（本地日志上报 F2 汇总）：页面 PV、下单转化漏斗、2FA 被拒次数——供复盘。
