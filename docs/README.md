# 山海企划 · 义卖活动一体化系统 项目文档集

> **项目代号**：SHS（ShanHai Sale System）
> **项目性质**：学校大型公益义卖活动「山海企划」配套的 下单—配货—库存管理一体化系统
> **活动规模**：单场 3–5 小时，预计人流 3,000–5,000 人次，面向全体大众开放
> **团队规模**：2 人全栈小队（A：Rust 后端 / B：小程序与现场设备）
> **文档版本**：v1.1　|　**密级**：内部　|　**编制日期**：2026-09（v1.1：云服务器 + CDN 分流，SIM 已办理）

---

## 1. 一句话概述

观众用微信小程序完成「入场核验 → 线上浏览 → 排队下单 → 凭 2FA 码提货 → 出口领纪念品」的全流程；员工用同一个小程序的高权限角色完成「检票、队列校验、配货打票、提货核销、纪念品发放」；**两台云服务器全公网部署**——前端聚合机（16C32G，shs-catalog + shs-trade 双进程，库存同进程直读 SSOT 零漂移）+ BE 账本机；商品图片/静态经 **CDN 分流**；现场 AP + CPE（SIM 已办理）仅承担终端接入，顾客也可走自身蜂窝直连云端。

## 2. 系统组成（五大构件）

| 构件 | 形态 | 核心职责 |
|---|---|---|
| 客户端 | 微信小程序（H5） | 登录、GNSS 围栏、商品浏览、下单、2FA 客户码出示、设备指纹 |
| 员工端 | 同一小程序（差异化权限） | 员工授权绑定、入口检票、队列校验、提货核销、纪念品发放、小票打印 |
| 前1（交易） | 聚合机 shs-trade 进程 | 交易入口：入场登记、订单校验与限购、库存权威计算（SSOT）、订单缓存与可靠投递 |
| 前2（目录） | 聚合机 shs-catalog 进程 | 目录服务：商品信息/静态资源（CDN 源站）、匿名浏览接口、库存展示（同进程直读 SSOT）与推送 |
| 后端服务器（BE） | Rust 服务 · 独立云 ECS 公网部署 | 核心账本：订单落库、订单/任务分发、员工实名与鉴权、员工端 WS 长连接、纪念品台账 |
| CDN | 云 CDN 边缘节点 | 商品图片/静态边缘分发（分流≈90% 读流量），未命中回源聚合机 |

## 5. 术语表

| 术语 | 全称/释义 |
|---|---|
| F1 / 前1 | 前置交易服务（shs-trade 进程），订单接入与库存权威（部署于前端聚合机） |
| F2 / 前2 | 前置目录服务（shs-catalog 进程），商品信息与静态资源（同机双进程） |
| 前端聚合机 | 华为云 ECS 16C32G（500M 带宽峰值），承载 F1+F2 双进程与 TLS 网关，库存同进程直读 |
| BE / 后端 | 后端服务器（backend-core），订单账本与员工调度 |
| 2FA 客户码 | 客户端按 `HMAC(密钥, 微信ID+时间窗)` 每 2s 刷新的动态码，员工扫码核验身份 |
| 入场动态码 | 入口大屏展示的动态二维码（入口 ID + 时间戳 + 签名），客户端离线校验 |
| 设备指纹 | 由微信环境参数组合哈希出的设备唯一标识 |
| SSOT | Single Source of Truth，库存的权威数据源（F1） |
| WAL | Write-Ahead Log，F1 订单可靠投递的本地持久化日志 |
| GNSS 围栏 | 校验用户定位落在会场附近才放行下单功能 |
| ULID | 有序唯一 ID，用作订单号 |
| CPE | 客户端前置设备（QCI6），现场统一公网出口（4G/5G，SIM 已办理） |
| CDN | 内容分发网络：商品图片/静态在边缘命中（≈90% 读流量），未命中回源 F2 |
